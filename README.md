# ショキミツ (syokimitsu) プロジェクト詳細仕様書・管理者マニュアル

## 1. プロジェクト概要
「ショキミツ」は、保守契約の年数管理および見積作成業務のデジタルトランスフォーメーション（DX）を目的とした支援ツールです。
従来、手動の計算やExcel操作に頼っていた保守契約の更新に伴う複雑な金額計算を自動化し、ヒューマンエラーの削減と業務効率の劇的な向上を実現します。

### ビジネス上のメリット
- **計算精度の向上**: 契約の重複や空き期間に伴う日割り計算をシステム化。
- **工数削減**: Excel雛形への自動流し込みにより、見積作成時間を短縮。
- **ガバナンス強化**: Google OAuth 認証による、社内ユーザー限定のセキュアなアクセス。

---

## 2. システム構成・技術スタック
モダンな Web 技術を採用し、メンテナンス性とパフォーマンスを両立しています。

- **Frontend/Backend**: [Next.js 14 (App Router)](https://nextjs.org/)
- **Programming Language**: [TypeScript](https://www.typescriptlang.org/)
- **Authentication**: [NextAuth.js](https://next-auth.js.org/) (Google OAuth 2.0 連携)
- **Styling**: Vanilla CSS / CSS Modules (Tailwind 等の依存を排除したクリーンな実装)
- **Data Processing**: 
    - [XLSX (SheetJS)](https://sheetjs.com/): Excel雛形（`DLCare 見積書ひな形.xlsx`）への出力。
    - [CSV Parser]: 巨大なマスタデータ（`master.csv`）の高速処理。

## 3. 主要機能の技術仕様

### 3.1. 保守契約計算機（計算ロジックの詳細）
本システムの核心部であり、複雑な契約調整パターンを網羅しています。

#### A. 契約重複（オーバーラップ）調整
新旧契約が重複する場合、重複期間に応じた日割り減額分を自動算出します。
- **ロジック**: `(月次単価) × (重複月数)` を基本とし、端数日数は日割り計算を適用。
- **自動摘要**: 明細行に「重複期間に伴う充当額」として自動記載。

#### B. 空き期間（ブリッジ）補充
前回の契約終了から今回の開始までに空きがある場合、その期間の保守費用を加算します。
- **ロジック**: 欠落期間分を月割・日割で算出し、見積に反映。

#### C. REAL4 同期ルール (3ヶ月無料)
特定の契約同期条件下において、「最大3ヶ月分を無料とする」という社内ルールを自動適用します。
- **自動注釈**: 条件合致時、備考欄に「REAL4同期に伴う特別規定適用」を自動追記。

#### D. 金額非表示設定の製品対応
「S/F Arris」等、見積書上では金額を表示しない仕様（`hidePrice: true`）の製品であっても、計算機内ではマスタの価格を参照して正確な試算が行えるバイパスロジックを実装しています。

### 3.2. 見積作成エンジン
- **Excel統合**: ブラウザ上で入力した内容を、指定のExcelセル番地へ正確に出力。
- **動的行追加**: 製品マスタから選択した商品を、見積明細へワンクリックで追加。
- **自動計算**: 小計、消費税、合計金額をリアルタイムで算出。

## 4. セキュリティとデータ管理

### 認証・認可
- **Google ログイン**: 社内の Google Workspace アカウントを利用。
- **ミドルウェア保護**: 未認証ユーザーによる API やページへのアクセスをサーバーサイドで遮断。

### データソース
- **マスタデータ**: `master.csv` (約3.6MB) を利用。
- **キャッシュ最適化**: Next.js のキャッシュ制限（2MB）を考慮し、API ルートでは `no-store` 設定を適用して巨大なデータの安定的な配信を実現。

## 5. 運用・トラブルシューティング
開発・保守時に発生した主要な課題と解決策をアーカイブしています。

- **ポート 3000 の競合**: Node.js プロセスが残留した場合のクリーンアップ手順を確立。
- **API 通信エラー**: 巨大データ fetch 時のメモリ/キャッシュエラーをミドルウェアレベルで修正済み。
- **ドキュメント管理**: `docs/` ディレクトリに、各機能の実装計画（`implementation_plan.md`）と検証記録（`walkthrough.md`）をフェーズごとに保存しています。

## 6. セットアップガイド

1. **環境構築**:
   ```bash
   npm install
   ```
2. **環境変数 (`.env.local`)**:
   - `GOOGLE_CLIENT_ID`: Google Cloud Console より取得。
   - `GOOGLE_CLIENT_SECRET`: 同上。
   - `NEXTAUTH_SECRET`: ランダムな文字列。
3. **起動**:
   - 開発用: `npm run dev`
   - 本番用: `npm run build && npm start`
