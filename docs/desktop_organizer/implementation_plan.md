# デスクトップ整理アプリ (Desktop Organizer) 実装計画

デスクトップ上のファイルを自動でわかりやすい名前のフォルダに分類・移動し、誤って整理した場合に「元に戻す（Undo）」ことができるGUI付きアプリケーションを作成します。

## ユーザー承認が必要な事項 (User Review Required)

> [!IMPORTANT]
> 1. **使用技術・言語の確認**
>    軽量かつすぐに動かせるデスクトップアプリとして **Python** と、Python用のモダンなGUIライブラリ（`CustomTkinter` または標準の `tkinter`）を用いることを提案します。PCにPythonがインストールされていることが前提となりますが、サクッと動作するアプリを作成するのに適しています。（※もし Node.js などを優先的に使いたい場合はお知らせください）
> 2. **フォルダーの命名規則と作成場所**
>    デスクトップ上に `デスクトップ整理` （もしくは現在の年月のもの、例:`デスクトップ整理_202604`など）という親フォルダを作り、その中に直感的にわかりやすい日本語のフォルダを作成して振り分けます。
>    - `📷 画像・写真`（.jpg, .png, .gif, .bmpなど）
>    - `📄 文書・資料`（.pdf, .docx, .txtなど）
>    - `📊 表計算・データ`（.xlsx, .csvなど）
>    - `📦 圧縮ファイル`（.zip, .lzhなど）
>    - `📦 その他` (上記以外のファイル)
>    ※アプリケーションのショートカット（.lnk）や、既存の「フォルダ」はそのままデスクトップに残す仕様を想定しています。
> 3. **元に戻す（Undo）機能の仕組み**
>    整理を実行した時、内部の設定ファイル（`undo_log.json`）に「どのファイルを・どこへ移動したか」の記録を保存します。「元に戻す」ボタンを押すと、この履歴を読み込み、元のデスクトップへファイルを復元します。

## 検証プラン (Verification Plan)

### 手動検証
1. アプリを起動し、GUIが表示されることを確認。
2. デスクトップ上に検証用のダミーファイル（テキスト、画像等）を生成し、「整理ボタン」を押して仕様通りのフォルダへ移動することを確認。
3. 移動後、「元に戻すボタン」を押し、アプリの履歴読み込みによる切り戻しが正常に行われ、ファイルが元の位置へ戻るかを確認。
