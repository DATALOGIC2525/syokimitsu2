# 修正内容の確認 (Walkthrough)：データロジック製品見積システムへの拡張・全面GUI刷新

既存の初期見積ソフト「ショキミツ」の見積テンプレート・A4印刷レイアウト・計算ロジックを完全に継承した上で、株式会社データロジックの全製品群に対応した**「ソフミツ」全面モダンGUI**へ刷新しました。

## 1. 全面刷新したGUIの全体構成（4つの専用ワークスペース）

画面上部の**スティッキーナビゲーションバー**から、用途に応じた4つの専用ワークスペースをワンクリックで切り替えられます。右端には常に現在の**税込合計金額ピル**と**「📊 Excel出力」「🖨️ 印刷 / PDF出力」**ボタンが配置されています。

- **対象ファイル**: [page.tsx](file:///d:/ソフト開発/SOFUMITSU/src/app/page.tsx), [page.module.css](file:///d:/ソフト開発/SOFUMITSU/src/app/page.module.css), [globals.css](file:///d:/ソフト開発/SOFUMITSU/src/app/globals.css), [route.ts](file:///d:/ソフト開発/SOFUMITSU/src/app/api/export-estimate/route.ts)

### ① `📝 見積書作成` ワークスペース（2ペイン構成）
1. **STEP 1：基本情報・見積条件（横並びコンパクトカード）**
   - 得意先名、見積タイトル、拠点（本社/東京）・担当者、発行日・見積番号、取引条件（納期・支払条件・受渡場所・有効期限）を1画面で見渡せる6カラムグリッドに整理。
   - 右上のセグメントボタンで **「📄 通常見積（製品・システム）」** と **「🛡️ DL Care保守内訳」** モードを即座に切り替え可能。
2. **STEP 2：見積明細の作成（左：製品カタログ ／ 右：見積明細シートの2ペイン分割）**
   - **左ペイン（データロジック製品カタログ）**:
     - カテゴリピル（`CAD・BIM系` / `計画・管理系` / `加工・最適化系` / `クラウド・サポート系` / `その他`）とインクリメンタル検索で素早く製品を絞り込み。
     - カタログカードをクリックするだけで、右側の見積明細へ `品目名`・`単価`・`単位`・`備考` がワンクリックで追加されます（不要な時は「◀ カタログを隠す」で明細表をフル幅表示可能）。
   - **右ペイン（見積明細シート）**:
     - 各行で「📚 マスタから選択してセット...」プルダウンからの呼び出し、品目名・備考の自由編集、一体型ピルによる `数量 | 単位` 変更、`¥` 付き単価・金額調整、行の上下移動・削除に対応。
     - フッターから「`＋ 空の自由入力行を追加`」「`🔻 一式お値引き行を追加`」「`🗑️ 明細をクリア`」をワンクリックで実行でき、右下に小計・値引き・消費税・合計金額がリアルタイム集計されます。

### ② `🗂️ 金額マスター・設定` ワークスペース（フル画面設定画面）
従来の狭いモーダルを廃止し、見やすく設定しやすいフル画面の専用ワークスペースに刷新しました。
1. **製品・品目マスター管理（一覧・クイック追加・インライン編集）**
   - 画面上部の**「＋ 新規品目のクイック登録バー」**から、カテゴリ・製品名・標準単価・単位・備考を入力して即座にマスターへ追加可能。
   - 一覧テーブル上で全項目の**直接インライン編集**、上下並び替え（▲/▼）、削除、CSVエクスポート、初期データへのリセットが行えます。
2. **CSV / Excelコピペ一括登録（リアルタイムプレビュー付き）**
   - 左側に**CSVファイルアップロード（UTF-8 / Shift-JIS自動判定）**および**Excel・スプレッドシートからのコピー＆ペースト入力欄**を配置。
   - 貼り付けた瞬間に右側の**「取り込みプレビュー表」**へ解析結果（カテゴリ・製品名・単価・単位・備考）が一覧表示されるため、登録前に内容をひと目で確認してから安全に一括登録・上書き更新できます。
3. **担当者マスター設定**
   - 見積書の発行元・押印欄に連動する担当者名を、カード型のインラインリストで簡単に追加・編集・削除できます。

### ③ `👁️ 見積書プレビュー` ワークスペース（A4実寸ライブプレビュー）
- 印刷ボタンを押す前に、画面上で**「ショキミツ」と完全に同一のA4見積書レイアウト**（宛名、金額、取引条件、会社ロゴ・角印、電子印鑑、13行明細表、備考欄）をリアルタイムに確認できます。

## 2. DL Care保守内訳モード＆顧客所持ソフト連動の修正
- **原因**: マスター先頭に製品販売用データ（`S/F REAL4` ¥2,500,000等）が追加されたことで、顧客の所持ソフトをクリックした際の名前マッチングが製品販売用マスタにヒットしていた点、およびモード切替時に既存明細が変換されていなかった点を解消しました。
- **改修内容**:
  1. **顧客所持ソフトクリック時のDL Care専用マッチング (`findBestDlCareProduct`)**:
     - 「💡 顧客の所持ソフト」をクリック（または「🛡️ 所持ソフトをすべてDL Care保守内訳に一括セット」を実行）すると、自動的に `🛡️ DL Care保守内訳モード` に切り替わり、必ず `DL Care保守内訳` マスタ（`S/F REAL4 Type1〜5` 年額¥120,000＋台数階段価格、`S/F NCあなあけ` ¥60,000、`S/F Arris` 金額非表示など）とマッチングして `┣S/F REAL4 (2台分: \150,000)` の形式で明細に追加されます。
  2. **モード切替時の既存明細の自動相互変換 (`handleSwitchEstimateMode`)**:
     - `📄 通常見積モード（製品見積）` ⇔ `🛡️ DL Care保守内訳モード` を切り替えた際、すでに入力されている明細行も自動的に該当モードの品目表記・単価・計算方式へ再計算・変換されます。
  3. **DL Care保守内訳モード時の画面表示とカタログ連動**:
     - `🛡️ DL Care保守内訳モード` 選択時は、左ペインのカタログと各行のマスタ選択プルダウンが `DL Care保守内訳マスタ` 専用表示に切り替わり、明細テーブルの上部に1行目 `ソフトウェア保守サービス DL Care(年額）`・2行目 `【内訳（対象ソフトウェア）】` の固定見出しがプレビュー表示されます。

## 3. セキュリティの抜本的強化（多層防御・ゼロトラスト対策）
- **対象ファイル**: [security.ts](file:///d:/ソフト開発/SOFUMITSU/src/lib/security.ts), [middleware.ts](file:///d:/ソフト開発/SOFUMITSU/src/middleware.ts), [auth.ts](file:///d:/ソフト開発/SOFUMITSU/src/auth.ts), [next.config.ts](file:///d:/ソフト開発/SOFUMITSU/next.config.ts), [customers/route.ts](file:///d:/ソフト開発/SOFUMITSU/src/app/api/customers/route.ts), [export-estimate/route.ts](file:///d:/ソフト開発/SOFUMITSU/src/app/api/export-estimate/route.ts), [export-contract/route.ts](file:///d:/ソフト開発/SOFUMITSU/src/app/api/export-contract/route.ts)
- **実装した主な防御機構**:
  1. **ミドルウェアの Fail-Open 脆弱性の解消（Fail-Closed 化）**:
     - 従来 `catch (err)` 時に `NextResponse.next()` で未認証リクエストを素通しさせていた脆弱性を修正し、エラー発生時も必ず遮断（APIは `401 Unauthorized` JSON返却、画面は `/login` へリダイレクト）する設計に変更しました。
  2. **全APIルート内部でのゼロトラスト認証・CSRF検証・レート制限 ([`enforceApiSecurity`](file:///d:/ソフト開発/SOFUMITSU/src/lib/security.ts#L98-L148))**:
     - ミドルウェアのバイパス攻撃（CVE-2025-29927等）に対抗するため、`/api/customers`・`/api/export-estimate`・`/api/export-contract` の各API内部でも毎回サーバーサイドで `await auth()` セッション検証を実行。
     - POSTリクエスト時は `Origin` / `Referer` ヘッダーによる同一オリジン（CSRF）検証を強制。
     - IP・エンドポイント単位のスライディングウィンドウ方式レートリミッター（`429 Too Many Requests`）を導入し、ブルートフォース攻撃やDoS攻撃、顧客データの大量スクレイピングを遮断。
  3. **Excel / CSV 数式インジェクション対策 & Word XMLインジェクション対策**:
     - `=`, `+`, `-`, `@` 等で始まる悪意あるコマンド文字列がExcel見積書やCSVファイルに埋め込まれる攻撃（Formula Injection）を [`sanitizeForSpreadsheetCell`](file:///d:/ソフト開発/SOFUMITSU/src/lib/security.ts#L164-L171) で無害化。
     - Word契約書生成API（`/api/export-contract`）のすべての動的挿入値に厳格なXMLエスケープ・数値範囲制限・ペイロード上限（100KB / 最大50明細）を適用。
  4. **Google OAuth認証・セッション管理の強化 ([`auth.ts`](file:///d:/ソフト開発/SOFUMITSU/src/auth.ts))**:
     - Googleアカウントのメール検証済みフラグ（`email_verified !== false`）を必須化。
     - セッション有効期限を8時間（業務サイクル）に設定し、放置端末からのセッションハイジャックを防止。
  5. **HTTPセキュリティヘッダーの全面導入 ([`next.config.ts`](file:///d:/ソフト開発/SOFUMITSU/next.config.ts))**:
     - `Content-Security-Policy (CSP)`, `X-Frame-Options: DENY`（クリックジャッキング防止）, `X-Content-Type-Options: nosniff`, `Strict-Transport-Security (HSTS)`, `Permissions-Policy`, `Referrer-Policy` を全ルートに付与。
     - `poweredByHeader: false`（フレームワーク情報の隠蔽）および `productionBrowserSourceMaps: false`（本番ソースコードの逆コンパイル防止）を有効化。
