# データロジック製品見積システム拡張 実装計画 (Implementation Plan)

既存の初期見積ソフト「ショキミツ」のテンプレート・計算ロジック・UI操作性を完全に継承しつつ、株式会社データロジックの全製品群に対応した「金額マスター管理機能」および「見積作成画面との連動機能」を実装します。

## 1. 概要と基本方針
- **見積テンプレートの完全維持**:
  - 「ショキミツ」の見積書レイアウト（HTML/CSS印刷レイアウトおよびExcel出力テンプレート `テンプレート.xlsx`）、ヘッダー情報（宛名、住所、納入場所、有効期限、支払条件、発行日、社判ロゴ、担当者）、明細表の列構成（NO / 品名 / 数量 / 単価 / 金額 / 備考）を一切崩さずに維持します。
- **見積表示モードの切り替え**:
  - **通常見積モード（デフォルト）**: 1行目から選択したデータロジック製品・オプション・諸経費などの明細を順番に印字・Excel出力します。
  - **DL Care保守内訳モード**: 従来のショキミツ同様、1行目に「ソフトウェア保守サービス DL Care(年額)」、2行目に「【内訳（対象ソフトウェア）】」を表示し、3行目以降に内訳明細を表示します。

## 2. 変更・新規実装するファイル

### [MODIFY] `src/app/page.tsx`
1. **金額マスターデータ構造 (`Product`) の拡張と初期サンプルデータの用意**
   - マスター項目:
     - `id`: 一意識別子
     - `category`: カテゴリ（`CAD・BIM系`、`計画・管理系`、`加工・最適化系`、`クラウド・サポート系`、`その他`）
     - `name`: 製品・品目名
     - `basePrice`: 標準単価
     - `unit`: 単位（`式`、`ライセンス`、`本`、`年額`、`月額`、`人日`、`台` など）
     - `remarks`: 備考（標準の摘要テキスト）
     - `type`: `'flat'`（単価×数量） | `'tiered'`（REAL4保守の階段価格計算）
     - `hidePrice`: 金額非表示設定
   - 初期サンプルデータとして以下のデータロジック製品群をプリセット登録:
     - **CAD・BIM系**: `S/F REAL4`、`BIM/Revit連携システム`、`S/F Arris4`
     - **計画・管理系**: `S/F 生産計画`、`S/F 出荷計画`、`S/F 出来高管理`、`S/F 原価管理4`、`S/F 見積積算4`
     - **加工・最適化系**: `S/F 最適取合4`、`S/F NCあなあけ3`
     - **クラウド・サポート系**: `S/F Com-Pass`、`DL Care`、`保守サポート`
     - **その他**: `オプションモジュール`、`導入指導・セットアップ費用`、`ハードウェア・諸経費`

2. **金額マスター管理モーダルの強化**
   - カテゴリ絞り込みタブ・キーワード検索フィルタの追加
   - 画面上での個別追加・金額編集・単位/備考編集・削除・上下並び替え（▲/▼）・初期データ復元機能
   - **一括登録（インポート）＆エクスポート機能**:
     - CSVファイルのアップロード取込（UTF-8 / Shift-JIS 対応）
     - Excelやスプレッドシートからのコピー＆ペースト（TSV/CSV形式）による一括登録・更新
     - 取込モード（「既存マスターへ追加・同名品目を更新」または「既存マスターをすべて置換」）の切り替え

3. **見積作成画面と金額マスターの連動**
   - **クイック検索＆カテゴリ絞り込み呼び出し**:
     - 明細上部および各明細行で、カテゴリ絞り込み＋インクリメンタル検索またはプルダウンから製品を選択すると、マスターの「品目名」「単価」「単位」「備考」を自動セットし、数量×単価で金額を自動算出します。
   - **柔軟な編集の維持**:
     - マスター呼び出し後の「数量の変更」「単価の個別調整」「品目名・単位・備考の自由編集」に対応。
     - 「`+ マスターから明細を追加`」「`+ 自由入力行を追加`」「`+ 一式値引き行を追加`（マイナス金額対応）」の3種類の行追加ボタンを用意。
   - **見積モード切替**:
     - 「通常製品見積モード」と「DL Care保守内訳モード」をワンクリックで切り替え可能にします。

### [MODIFY] `src/app/page.module.css`
