# 担当者マスタ管理機能の実装計画

先ほど固定のリストとして追加した「担当者」のプルダウン選択肢を、製品マスタと同様に画面上から自由にメンバーを追加・削除・管理できるようにする機能を実装します。

## 概要

現在、「製品マスタ設定」のモーダル画面で製品の一覧や価格を設定できるようになっています。
この画面を拡張し、「担当者」のリストも設定・保存できるようにすることで、見積書作成時のプルダウンに表示されるメンバーを柔軟に変更できるようにします。

## 提案する変更内容

### [MODIFY] `src/app/page.tsx`
1. **担当者データの状態管理と保存**
   - 新しく担当者リストを管理するための変数を追加します。
   - 初期値として、先ほど追加したメンバー（坂下、林、野上、永井、坂倉、倉増）を設定します。
   - 追加・削除されたデータはローカルストレージ（お使いのブラウザ）に自動保存され、次回以降も引き継がれるようにします。

2. **マスタ設定画面（モーダル）の拡張**
   - 既存の「製品マスタ設定」画面（モーダル）の中に、新しく「担当者マスタ設定」エリアを追加します。
   - 担当者の名前を追加するための入力欄とボタン、および削除ボタン（✕）を配置します。

3. **プルダウンの動的化**
   - 左サイドバーの「基本情報」にある担当者プルダウンを、上記のマスタ設定で管理されているリストから自動生成するように変更します。
