# ショキミツ - ソフトウェア仕様書

## 1. 構成環境 (Technology Stack)

### 1.1. 基盤技術
- **フレームワーク**: Next.js 14.2.3 (App Router)
- **プログラミング言語**: TypeScript
- **ランタイム**: Node.js

### 1.2. 主要ライブラリ
- **認証**: NextAuth.js (Google Provider)
- **Excel操作**: ExcelJS, file-saver
- **CSV解析**: PapaParse
- **共通ユーティリティ**: fetch (HTTP), LocalStorage (永続化)

## 2. システムアーキテクチャ

### 2.1. ディレクトリ構造
- `src/app/`: App Router 構造の各ページ・レイアウト。
- `src/app/api/`: サーバーサイドの処理（顧客取得、Excel生成）。
- `src/middleware.ts`: 認証チェックとリダイレクト制御。
- `public/`: 画像、ファビコン、Excel 雛形等の静的ファイル。

### 2.2. データフロー
1. クライアント側から `/api/customers` へ GET リクエストを送信。
2. サーバー側（API ルート）が Google Spreadsheet の CSV エクスポート URL をフェッチ。
3. PapaParse で CSV をオブジェクト配列へ変換し、クライアントへ返却。
4. クライアント側（page.tsx）で検索・選択を行い、LocalStorage や State で管理。
5. `/api/export-estimate` へ JSON データを POST し、サーバー側で Excel ファイルを生成。
6. クライアント側で blob として受け取り、ダウンロード。

## 3. ロジック仕様

### 3.1. 金額計算ロジック (`calculatePrice`)
- **製品タイプ**: `tiered` (段階価格) と `flat` (定額) の 2 種類。
- **REAL4 シリーズ (tiered)**:
    - 1台: 基本年額 (120,000円)
    - 2台: 基本年額 + 30,000円
    - 3台: 基本年額 + 60,000円
    - 4台: 基本年額 + 90,000円
    - 5台以上: 基本年額 + 120,000円
- **定額製品 (flat)**: 基本年額を一律に適用。台数による変動なし。
- **非表示設定 (`hidePrice`)**: 見積書への金額印字を抑止するが、システム内部（電卓機能等）ではマスタの金額を参照して計算可能。

### 3.2. 保守調整計算ロジック (`getSubCalcResult`)
- **月数差分算出**: `(新契約開始年月) - (旧契約終了年月)` により月単位の差分（`diff`）を算出。
- **重複 (diff > 0)**: 
    - 重複月数 × (年額/12) = 充当額 (マイナス)
    - 新年度分 = 年額 - 充当額
- **空白 (diff < 0)**:
    - 空き月数 1〜3ヶ月: 加算なし（無料）。
    - 空き月数 4ヶ月以上: 空き月数 × (年額/12) = 加算（ブリッジ）額。
    - 新年度分 = 年額 + 加算額

### 3.3. 顧客データ正規化 (`formatCompanyName`)
- 「㈱」「(株)」「㈲」などを「株式会社 」「有限会社 」へ統一し、会社名と法人名の間に半角スペースを挿入。

## 4. API 仕様

### 4.1. `GET /api/customers`
- **概要**: 最新の顧客・ライセンス情報の取得。
- **制約**: Next.js のキャッシュ制限（2MB）を回避するため、`no-store` を指定し常に外部より最新をフェッチ。

### 4.2. `POST /api/export-estimate`
- **概要**: 入力内容を「DLCare 見積書ひな形.xlsx」へ出力。
- **主要セル番地マッピング**:
    - `G2`: 見積日付
    - `A4`: 会社名
    - `F13`: 合計金額
    - `A16`: 明細品名、`E16`: 明細単価、`F16`: 明細金額（ループ処理）

## 5. UI/UX 仕様
- **CSS Modules**: `page.module.css` によるスコープ付きスタイリング。
- **レスポンシブ**: デスクトップ環境を主眼に置いた 2 カラム構成。
- **印刷**: メディアクエリ `@media print` により、UI 操作パネルを隠し、見積書部分のみを出力。

## 6. セットアップ・デプロイ手順
- **起動**: `起動.bat` インタフェースより `npm run dev` を実行。
- **環境変数**: `.env.local` への `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `NEXTAUTH_SECRET` の設定が必要。
