# ショキミツ - 要件定義書

## 1. 概要
「ショキミツ」は、保守契約の年数管理と見積作成業務を効率化・自動化するための Web アプリケーションです。
既存の Excel ベースの運用をシステム化することで、複雑な日割り計算のミスを防止し、業務リードタイムの短縮を実現します。

## 2. 背景と目的

### 2.1. 現状の課題
- **計算の複雑性**: 保守契約の「重複（追い出し）」や「空き期間（ブリッジ）」に伴う日割り計算が複雑であり、手計算によるミスが発生しやすい。
- **データの散逸**: 顧客ごとの所持ソフトウェア情報やファイルNo.の確認に手間がかかる。
- **テンプレート管理**: 複数の Excel 雛形への手入力が必要で、転記ミスのリスクがある。

### 2.2. システムの目的
- 保守契約の整合性を保ちながら、精度の高い金額試算を提供する。
- 顧客マスタとの連携により、入力作業を最小化する。
- 承認済みの Excel テンプレート（DLCare 見積書ひな形.xlsx）への自動出力を可能にする。

## 3. ターゲットユーザー
- 営業担当者（見積作成・提示）
- 契約管理担当者（契約内容のチェック・更新）

## 4. 機能要件

### 4.1. 顧客・マスタ検索機能
- 外部データ（Google スプレッドシート）をソースとした最新の顧客情報の取得。
- ファイルNo.、ユーザー名、ふりがなによる「あいまい検索」機能。
- 検索結果に基づく、住所、郵便番号、所持ソフトウェア情報の自動反映。

### 4.2. 見積書作成機能
- **動的明細管理**: ソフトウェア製品の追加・削除、並び替え機能。
- **価格自動算出**:
    - REAL4 シリーズ：ライセンス台数に応じた段階価格（Tiered pricing）の適用。
    - その他システム：基本年額の適用。
- **編集機能**: 自動算出された金額の手動上書き、名称の自由編集。

### 4.3. 保守調整計算機（電卓機能）
- **期間計算**: 新規契約開始日と既存契約終了日の差分（月数）を自動算出。
- **重複調整（充当額）**: 重複期間分の月次単価をマイナス計上するロジック。
- **空白調整（ブリッジ）**: 空き期間（4ヶ月以上）の保守費用をプラス計上するロジック。
- **REAL4 同期ルール**: 3ヶ月以内の差分について無償化する特別規定の自動判定。

### 4.4. 出力機能
- **Excel 出力**: 既存の `DLCare 見積書ひな形.xlsx` の指定セルへ、見積情報をマッピングして出力。
- **PDF/印刷**: ブラウザ標準の印刷機能を利用した、整形済みの見積書プレビュー。

### 4.5. セキュリティ・認証
- **Google OAuth**: 社内ドメインユーザーによるログイン制限。
- **アクセスコントロール**: 認証済みユーザーのみがアプリケーションを利用可能。

## 5. 非機能要件

### 5.1. 操作性 (Usability)
- 入力項目を変更した際、再計算ボタンを押さずにリアルタイムで合計金額が更新されること。
- 直感的な UI（モーダル表示、チェックボックスによる自動計算の ON/OFF 制御）。

### 5.2. 信頼性・正確性
- 金額計算（日割り、消費税等）は社内規定に準じ、誤差が発生しないこと。
- 重大なエラー（データ取得失敗等）が発生した際、ユーザーに適切な通知を行うこと。

### 5.3. 保守性
- 製品マスタや単価設定をアプリケーション上の「製品マスタ設定」から変更可能にする（LocalStorageによる一時保存対応）。
