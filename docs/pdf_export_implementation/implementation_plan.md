# 見積書PDF出力機能の実装計画

既存の「Excelテンプレート出力」機能を応用し、作成したExcelファイルをバックグラウンドでPDFに自動変換し、ブラウザからダウンロードできるようにする機能を実装します。

## 概要

現在、「🖨️ 見積書(PDF/印刷)」ボタンはブラウザの標準印刷機能（`window.print()`）を呼び出しており、画面のHTMLをベースにしたレイアウトで印刷される仕様になっています。
ご要望の「エクセルをPDF出力した形式で」を実現するため、以下の変更を行います。

## 提案する変更内容

### 1. PDF出力用APIの新規追加
#### [NEW] `src/app/api/export-estimate-pdf/route.ts`
- 既存のExcel出力処理（`export-estimate`）と同様に、データ（金額や明細）をExcelテンプレートに流し込みます。
- 生成された一時的なExcelファイルを、サーバー側（ローカルPC）の PowerShell を経由して Microsoft Excel の機能でPDFファイルに変換します。
- 変換完了後、そのPDFファイルをクライアント（ブラウザ）に返却し、使用した一時ファイルは削除します。

### 2. フロントエンドのボタン挙動の変更
#### [MODIFY] `src/app/page.tsx`
- 「🖨️ 見積書(PDF/印刷)」ボタンをクリックした際の処理（`handlePrint`）を変更します。
- これまでの `window.print()` の代わりに、新しく作成したPDF出力APIを呼び出し、生成されたPDFをダウンロードする（またはブラウザの別タブで開く）処理に変更します。

## User Review Required

> [!IMPORTANT]
> **環境依存に関する注意事項**
> 本機能は、プログラムを実行しているPC本体（Windows環境）に **Microsoft Excel がインストールされていること** を前提とした仕組み（COMオブジェクト連携）を使用します。現在のようなローカル環境でのご利用であれば問題なく動作しますが、一般的なクラウドサーバー等にデプロイした場合には動作しなくなる点のみご留意ください。

> [!NOTE]
> **印刷フローの変更**
> 今まではボタンを押すとすぐにブラウザの印刷設定画面が開いていましたが、本実装後は「一度PDFファイルがダウンロードされる（またはPDFビューアが開く）」動作となり、そこから紙への印刷を行っていただくフローになります。
