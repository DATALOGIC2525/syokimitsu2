# PDF出力のレイアウト改善完了報告

自動でPDFに変換する仕組み（html2canvas）を削除し、ブラウザの標準印刷機能（`window.print()`）を呼び出す元の仕様に戻すことで、レイアウト崩れの問題を解消いたしました。

## 修正内容
1. **PDF出力ボタンの挙動変更**
   - 画面を無理やり画像化する処理を取りやめ、当初実装していた「ブラウザの印刷画面を開く」処理に戻しました。
2. **不要なモジュールの削除**
   - 画質低下やレイアウト崩れの原因となっていた外部ライブラリ（`html2canvas`, `jspdf`）をプロジェクトから完全にアンインストールし、コードを整理しました。

## 新しい運用フローと確認方法
画面をリロード後、以下の手順でPDFを保存してください。

1. 右側の「🖨️ 見積書(PDF/印刷)」ボタンをクリックします。
2. ご使用のブラウザの**印刷ダイアログ**が開きます。
3. プレビュー画面にて、レイアウトが崩れていないこと（担当者名なども表示されていること）をご確認ください。
4. 送信先（プリンター）の設定を **「PDFとして保存」**（または「Microsoft Print to PDF」）に変更し、保存ボタンを押してください。

※この手順を踏むことで、文字を選択・コピーできる最高画質かつレイアウト完璧なPDFが生成されます。
