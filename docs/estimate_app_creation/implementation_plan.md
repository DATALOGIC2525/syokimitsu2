# 見積作成アプリのアーキテクチャ・フレームワーク選定

今回作成する見積書作成アプリを効率的かつモダンな形で構築するため、以下の技術スタック（推奨ワークフレーム）を提案します。

## 推奨スタック
1. **Next.js (App Router)**
   - Reactベースのフルスタックフレームワーク。SPAのような高速な画面遷移と強力なルーティング機能を提供。現在フロントエンド開発の標準となっているため、機能拡張が容易です。
2. **TypeScript**
   - 型安全な開発を行うことで、金額計算や複雑な明細データの取り扱い（階層構造）時におけるバグを未然に防ぎます。
3. **Vanilla CSS (CSS Modules)**
   - クラス名の衝突を気にせず、より柔軟でプレミアムなデザインを作りこむために採用します。TailwindCSSなどは不要な依存を避けるため使用しません。
