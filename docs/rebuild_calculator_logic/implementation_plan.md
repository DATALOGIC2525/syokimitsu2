# 電卓計算（保守契約一本化・見積計算）の再構築計画

ご提供いただいたプロンプトの「計算ロジック」に基づき、現在の「電卓」機能を再構築します。

## 修正内容の概要

現在の「過去の未契約期間の月割り計算」から、「新契約（例：REAL4保守の4月更新）に合わせるための、旧契約（例：見積・取合保守）の未経過分・重複分の充当額（マイナス）の計算と差し引き」ロジックに変更します。
**※見積り明細への追加は行わず、純粋な試算用電卓として動作させます。**

### 1. データ構造の変更
現在の `calcRows`（各行独立）を廃止し、以下のように依存関係のある構造に変更します。
- **基準システム（新契約メイン）**
  - 製品選択（例：REAL4）
  - ライセンス数（年額の算出ベース）
  - 新契約開始年月（デフォルト：4月）
- **統合対象システム（保守期間を合わせるサブ）**
  - 製品選択（例：見積・取合保守）
  - ライセンス数
  - 旧契約の終了年月（例：6月）

### 2. 計算ロジックの実装
プロンプト通りに以下の計算を行います。
1. **重複期間（既払月数）**: `旧契約終了年月 - 新契約開始年月 + 1` の月数（例：4月開始～6月終了なら 3ヶ月）
2. **月単価**: `統合対象システムの年額 ÷ 12`（端数切り捨て）
3. **充当額（差し引き額）**: `月単価 × 既払月数`
4. **新年度分の見積額**: `統合対象の年額 - 充当額`
5. **合計請求額**: `基準システムの年額 + すべての統合対象システムの新年度分`

### 3. UI（モーダル）の再構築
表示内容を以下の出力形式に合わせます。
- 基準システムエリア（メイン）
- 統合対象システムエリア（サブ、追加/削除可能）
- 各サブシステムごとの「月単価」「既払月数」「充当額（マイナス）」の表示
- 「〇〇年〇〇月度 請求合計金額」の算出表示
- **「見積明細に追加」ボタンの廃止**
