# 修正内容の確認 (Walkthrough)

電卓機能において、「S/F Arris」等の特定の製品が「0円」と判定されてしまい、うまく計算されない（計算式が機能しない）不具合を修正しました。

## 修正内容詳細

### 計算ロジックでの「金額非表示」のバイパス (`src/app/page.tsx`)
- 本来の見積書作成機能においては、「S/F Arris」等は製品マスタ設定で **「金額印字・表示」のチェックが外されている（`hidePrice: true` と設定されている）** ため、明細上の金額を「0円」として出力する仕様になっていました。
- これが試算用の「金額計算（電卓）」機能にも適用されてしまっていたため、対象システムに選んでもベース金額が0円となり、値引きや月割計算が機能していませんでした。
- そこで、計算関数（`calculatePrice`）に「金額非表示設定を無視する（`ignoreHidePrice`）」という専用のパラメータを追加しました。
- 電卓機能内部でのみこのパラメータを有効化することで、**見積書には金額を出さない製品であっても、電卓（試算）上では正確な価格を取得して充当額や新年度分が計算される**ように修正しました。

## 動作確認結果

ブラウザ上の金額計算（電卓）にて、以下の点をご確認ください：
1. 基準システム、および統合対象システムのプルダウンから「S/F Arris」を選択する。
2. これまで「¥0」と表示されていた箇所に、本来の年額（例：¥36,000）が正しく計算され、そこから重複期間に応じた値引き額などが正常に機能すること。
