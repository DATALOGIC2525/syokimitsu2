# 修正内容の確認

「🧮 金額計算（電卓）」機能を実装しました。

## 実装内容
- 見積作成画面の「⚙️ 製品マスタ設定」ボタンの左隣に、「🧮 金額計算（電卓）」ボタンを新設しました。
- 電卓モーダルを開くと、以下の情報を入力できます：
  - **対象システム**: 製品マスタから選択（基本年額もあわせて表示されます）
  - **ライセンス数**: 複数台の場合に対応可能（基本価格計算ロジックを通します）
  - **過去の契約年・月**: 保守が切れた時期などを想定
  - **現在の契約年・月**: 今回の契約再開時期などを想定
- **計算ロジック**: 
  - (現在の年月 - 過去の年月) で「月数差分」を計算します。
  - 選択されたシステムの台数に応じた「基本年額」を 12 で割り、先ほどの「月数差分」を掛け合わせて金額を算出しています（月割り計算、小数点以下切り捨て）。
- **「見積りに追加」機能**:
  - 算出された金額をそのまま見積明細に1行追加できます。
  - 名称には自動で `┣[システム名] (XXXX年XX月～XXXX年XX月: Xヶ月分)` のように期間と月数差分が印字用として追記されます。

## テスト内容
- 電卓モーダルを開き、過去と現在の「年・月」を変更した際に、月数差分に応じた正しい金額がリアルタイムで計算・表示されることを確認しました。
- 「見積りに追加」ボタンを押下後、正しく明細行に追加され、全体の合計ルール（消費税など）にも正しく組み込まれることを確認しました。
