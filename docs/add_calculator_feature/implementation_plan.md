# 電卓（金額計算）機能の追加

システムと契約年月（現在・過去）を入力して金額を算出する計算機機能を追加します。

## ユーザーの確認が必要な項目 (User Review Required)
> [!IMPORTANT]
> **計算式（ロジック）について教えてください。**
> 当該システム（例：「S/F REAL4」）と、それぞれの年・月の入力値から、具体的にどのような計算式で金額を算出するのか教えてください。
> 
> 例： `(現在の年月 - 過去の年月) × 各システムの月額料金` 
> もし月額計算の場合、システムごとの「月額料金」はどのように定義されていますか？既存の「基本価格(basePrice)」を使用しますか？

## 提案する変更内容

### page.tsx
#### [MODIFY] page.tsx
- ヘッダー部分（「⚙️ 製品マスタ設定」ボタンの近くなど）に、「🧮 電卓（金額計算）」ボタンを追加します。
- 電卓モーダル用のStateを追加します（`isCalcModalOpen`, `calcSystem`, `calcCurrentYear_Month`, `calcPastYear_Month`, `calculatedAmount`）。
- 電卓モーダルのUI（各種入力フォームと計算結果の表示エリア、および「見積り明細に追加する」ボタン）を追加し、モーダル内に表示します。
- モーダルで「対象システム」を選択する際は、製品マスタ（`productMaster`）から選択できるようにします。

### page.module.css
#### [MODIFY] page.module.css
- 電卓モーダル用のスタイルを追加します。入力枠を横並びにするなど、使いやすいデザインにします。

## 検証計画
### 手動検証
1. 開発環境（`npm run dev`）でアプリを起動し、電卓ボタンが正常に表示されることを確認する。
2. 電卓モーダルを開き、対象のシステム、現在・過去の契約年と月を入力できることを確認する。
3. 指定された計算式に基づいて正しい金額が表示されるか検証する。
4. 計算した情報をそのまま見積明細に反映できるか動作テストする。
